Key Takeaways

  • Microsoft Intune introduces the Allow EWS Retirement Alerts setting for macOS devices.
  • The setting is available under Declarative Device Management (DDM) in the Settings Catalog.
  • Administrators can configure EWS retirement notifications using a macOS configuration profile.
  • The setting supports macOS 27.2 and later.

In this post we are discussing, Configure Exchange Web Services (EWS) Retirement Alerts on macOS Devices using Intune. Microsoft Intune introduces a new macOS setting in the Settings Catalog to manage Exchange Web Services (EWS) retirement alerts. This setting allows administrators to control whether users receive notifications about the retirement of Exchange Web Services on their managed Mac devices. The new Allow EWS Retirement Alerts setting is available under the Declarative Device Management (DDM) section of the macOS Settings Catalog. Administrators can use this setting to manage EWS retirement notifications through an Intune configuration profile.

Table of Contents

Configure Exchange Web Services (EWS) Retirement Alerts on macOS Devices using Intune

This setting is supported on devices running macOS 27.2 and later. It provides administrators with an additional option to manage EWS retirement-related notifications across their organization’s Mac devices. In this post, we will be discussing the purpose and benefits of the Allow EWS Retirement Alerts setting and the steps to configure it using the Microsoft Intune admin center.

Get Started

To configure the Allow EWS Retirement Alerts setting, you need to create a macOS configuration profile in the Microsoft Intune admin center. This setting is available through the Settings Catalog under the Declarative Device Management section. You can use this configuration profile to manage Exchange Web Services retirement notifications on supported macOS devices.

Create Profile

To create a new macOS Settings Catalog policy, navigate to Devices in the Microsoft Intune admin center. Under Manage devices, select Configuration, and then click Create > New policy. This will open the profile creation page, where you can select the platform and profile type. Select macOS as the platform and Settings catalog as the profile type. Click Create to proceed with the policy configuration. The Settings Catalog allows you to search for and configure the available macOS settings from a centralized location.

Basic Details

On the Basics page, provide a suitable name and description for the configuration profile. For the Name field, enter Allow EWS Retirement Alerts. You can add a description explaining that this policy manages Exchange Web Services retirement notifications on macOS devices. In Description I gave a short detail of the policy: “If ‘false’, the system doesn’t alert the user that an Exchange account has lost, or is about to lose, access because Microsoft is ending support for Exchange Web Services“.

  • Once you have entered the required details, click Next to continue to the Configuration settings page.

Configuration Settings for EWS Retirement Alerts

On the Configuration settings page, click Add settings to open the Settings Picker. In the search box, search for Allow EWS Retirement Alerts to locate the required setting. You can also navigate through Declarative Device Management > Account > Account Settings to find this configuration. Select the Allow EWS Retirement Alerts setting from the search results. Once selected, close the Settings Picker to add the setting to your configuration profile.

  • You can now configure the required value for this policy.

Disable EWS Retirement Alerts Policy

After adding the setting, you can see the Allow EWS Retirement Alerts option under Configuration settings. By default, the setting is in the Disabled state in the policy configuration, meaning that you have not enabled the setting through this profile. You can review the available configuration before making changes. If false, the system doesn’t alert the user that an Exchange account has lost, or is about to lose, access because Microsoft is ending support for Exchange Web Services. Only applies to Exchange accounts installed by an organization.

Allow EWS Retirement Alerts Policy

To enable the policy, change the Allow EWS Retirement Alerts setting from Disabled to Enabled. This configuration allows macOS to display Exchange Web Services retirement alerts for organization-installed Exchange accounts. Enabling this setting helps users receive relevant notifications about EWS retirement. After enabling the setting, review the selected configuration and click Next to proceed. This setting is supported on macOS 27.2 and later.

Scope Tag

On the Scope tags page, you can configure the scope tags to determine which administrators can access and manage this configuration profile. Scope tags help organizations organize and delegate policy management based on their administrative requirements. Here, I selected the London scope tag for this policy. You can select the appropriate scope tag based on your organization’s requirements. After selecting the scope tag, click Next to continue.

Assignments

On the Assignments page, you can assign the configuration profile to the required user or device groups. Click Add groups under Included groups and select the groups that should receive this policy. Assigning the profile to the appropriate groups ensures that the EWS retirement alert configuration is deployed to the targeted macOS devices.

Here, I selected the HTMD Test Policy and HTMD CPC Test groups for this configuration profile. You can choose different groups according to your organization’s deployment requirements. Once the assignments are completed, click Next.

Review + create

On the Review + create page, you can review all the configuration details before creating the policy. Verify the policy name, platform, selected Allow EWS Retirement Alerts setting, scope tag, and group assignments to make sure everything is configured correctly. After reviewing the details, click Create to complete the policy creation process.

Policy Creation Confirmation

After clicking the Create button, Intune displays a notification window confirming that the configuration profile creation process has started. This notification indicates that the Allow EWS Retirement Alerts policy has been successfully submitted for creation. You can close the notification and return to the Configuration profiles page. The newly created policy will appear in the list of macOS configuration profiles.

Monitoring Status

After creating the configuration profile, you can monitor its deployment status from the Intune admin center. Navigate to Devices> Configuration and select the Allow EWS Retirement Alerts policy. Open the Device and user check-in status or Device assignment status report to review the deployment results.

You can check the succeeded, pending, error, and conflict statuses to understand how the policy is being applied to targeted devices. This helps administrators identify deployment issues and verify whether the configuration profile has reached the assigned macOS devices.
