Windows Web Sign-In now Supports Microsoft Entra Hybrid Joined Devices for Passwordless Authentication

Saved for offline reading · Open original ↗

Key Takeaways

  • Supports Microsoft Entra hybrid joined devices.
  • Enables passwordless Windows sign-in.
  • Supports FIDO2 keys, phone passkeys, and TAP.
  • Provides Kerberos access to on-premises resources.

Web sign-in now supports Microsoft Entra hybrid devices devices. Previously, this feature was available only on Microsoft Entra joined devices. Users can now sign in to Windows from the lock screen without entering a password.

Table of Content

Windows Web Sign-In Now Supports Microsoft Entra Hybrid Joined Devices for Passwordless Authentication

After a successful sign-in, Windows obtains a Kerberos ticket, which allows users to access on-premises file shares and internal websites. This means users can enjoy passwordless sign-in while continuing to use their organization’s internal resources.
