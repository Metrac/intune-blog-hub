Unified User-Centric Access Reviews Across Multiple Resources in Microsoft Entra ID

Saved for offline reading · Open original ↗

Key Takeaways

  • Catalog Access Reviews allow reviewers to review a user’s access to groups, applications, and custom resources in one place.
  • Resources must first be added to an Entra ID catalog before they can be included in a catalog access review.
  • Organisations can use multi-stage reviews, allowing managers and resource owners to participate.
  • Reviewers can use the My Access portal to approve or deny access and provide justification when required.
  • At the end of the review period, the system automatically applies approved or denied decisions, except for custom disconnected resources.

Catalog Access Reviews in Microsoft Entra ID Governance allow organizations to review a user’s access to multiple resources, including groups, applications, and custom disconnected resources, in a single review experience. This makes it easier for managers and resource owners to verify that users have the appropriate access and remove unnecessary permissions.

Unified User-Centric Access Reviews Across Multiple Resources in Microsoft Entra ID

To use this capability, resources must first be added to an Entra ID catalog. Organizations can then create a catalog access review, assign reviewers, and optionally configure multi-stage reviews. The feature requires Microsoft Entra ID Governance or Microsoft Entra Suite licensing. Note that changes made within 12 hours before a review starts may not be reflected in that review.

Beginning January 15, 2026, a linked Azure subscription is required to use Entra ID Governance features for guest users. Access review is limited to resources (groups, apps, and custom resources). Access packages are not supported yet and are coming soon. New resources may appear later as systems finish syncing updates.

  • Set the core configuration, including the Review Name and Description.
  • Define the specific resources (groups, apps, or custom resources) to include in the review.
  • Specify who will perform the review and set the recurrence/timeline.
  • Configure settings to customize the review interface and workflow for reviewers.
  • Determine automatic actions to take once the review period ends.
  • Finalize and verify all configured settings before launching the access review.

Details and Prerequisite

Review users’ access across all resource types including Entra ID and Azure resources as well as non-Entra ID and Azure resources. For example, you can use this review template to review all employees under a certain department. Currently it reviews Entra ID resources such as groups and access packages. More resource types are to be included/to launch in the future.
