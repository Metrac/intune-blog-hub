Microsoft Entra PIM for App Roles to Enable Just-in-Time Access and Reduce Persistent Application Privileges. PIM for App Roles allows administrators to give users eligible access to application roles. Users can activate these roles only when needed and deactivate them after completing their tasks. This helps reduce permanent access and improve application security.

Microsoft Entra PIM for App Roles to Enable Just-in-Time Access and Reduce Persistent Application Privileges

Applications with existing app roles can be managed directly through PIM without any additional application onboarding. To configure PIM for App Roles, administrators must first configure the app role settings and activation requirements, then assign eligible roles to users. Finally, they can enable Just-in-Time (JIT) activation so users can activate their assigned application roles only when needed.

You can access this feature from the Microsoft Entra admin center → ID Governance → Privileged Identity Management → App Roles (Preview).

This feature allows administrators to assign eligible or time-bound application roles and enable Just-in-Time (JIT) access. They can require MFA, justification, or approval before activation, configure activation duration and notification settings, manage application role assignments, and review activation history.
