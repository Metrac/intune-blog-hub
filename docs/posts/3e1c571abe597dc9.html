Microsoft Intune Adds New Device Naming Options to Windows Autopilot Device Preparation

Key Takeaways

  • New OOBE controls allow administrators to customize different parts of the Windows setup experience.
  • Device naming templates allow administrators to create a standard naming pattern for devices during enrollment.
  • These configuration options help organizations maintain a more consistent Windows device setup process.
  • The new naming option helps organizations reduce the need to manually rename devices after the enrollment process.

In this post, we are discussing Microsoft Intune Adds New Device Naming Options to Windows Autopilot Device Preparation. Microsoft Intune now provides additional configuration options in Windows Autopilot device preparation. These options give administrators more control over how Windows devices are configured during the setup process. One of the new options is Apply device name template. This allows administrators to create a naming pattern for Windows devices during enrollment.

Microsoft Intune Adds New Device Naming Options to Windows Autopilot Device Preparation

Device naming is also an important part of managing a large number of Windows devices. With the latest configuration update, Windows Autopilot device preparation now includes the Apply device name template option. When enabled, administrators can use the Enter a name field to define a naming pattern that can be applied to devices during the setup process.

What’s New

Intune Recently add some configuration settings under the Windows Out of Box Experience (OOBE). Microsoft has added the Apply device name template setting to Windows Autopilot device preparation in Intune. This setting allows administrators to configure a device naming template as part of the device preparation process.

Configure the Device Name Template using Intune

To configure the device name template, sign in to the Microsoft Intune admin center and navigate to Devices > Windows > Windows enrollment > Windows Autopilot device preparation. From here, you can create a new device preparation policy or edit an existing policy to configure the device naming option.

Under Device preparation policies, select +Create to create a new policy. You will then see 2 options such as Automatic and User-driven. Select User-driven to continue with the device preparation policy configuration.

Configure the Device Preparation Settings

After selecting User-driven, you will be taken to the Autopilot device preparation settings page. Go through the available sections, including Introduction, Basics, and Device group, and enter the required details in each section. Next, you will reach the Configuration settings page. Here, expand the Out-of-box experience settings section by clicking the drop-down arrow to view the available configuration options.

  • By default, the Apply device name template option is set to No.
  • To configure a custom naming pattern for the devices, this option needs to be enabled.

The Apply device name template setting allows administrators to create a naming template that can be used to assign names to devices during enrollment. This helps organizations maintain a consistent name for enrolled devices. To enable this setting, change Apply device name template from No to Yes. Once enabled, the Enter a Name field appears below the setting.

  • In the Enter a name field, enter the desired device naming pattern. Here, it showing MyCompany-%RAND:4%
