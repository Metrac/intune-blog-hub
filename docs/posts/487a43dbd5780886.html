Microsoft Intune Introduces Bulk eSIM Activation and Removal for Corporate-Owned Android Devices

Microsoft Intune allows IT administrators to remotely activate, manage, and provision cellular data plans via Bulk eSIM activation for multiple corporate-owned Android devices simultaneously, without needing physical SIM cards.

As you know that, traditionally setting up cellular connectivity on enterprise mobiles required inserting physical plastic SIM cards into each device or manually configuring them one by one. With native eSIM support integrated into Microsoft Intune and Android Enterprise, administrators can handle cellular deployment at scale directly from the cloud admin center.

Bulk eSIM Activation

Bulk activation of eSIM is available only in the updated bulk device actions experience. When you bulk wipe supported devices, Intune preserves eSIM data plans by default. You can select the option to remove eSIMs when the wipe should also remove the data plans. Personally owned Android Enterprise work profile devices aren’t supported. The following are the applied devices of this feature.

  • Android Enterprise corporate-owned fully managed devices (COBO)
  • Android Enterprise corporate-owned dedicated devices (COSU)
  • Android Enterprise corporate-owned devices with a work profile (COPE)

Bulk eSIM Activation on one Android Enterprise Device

In the Microsoft Intune admin center, select Devices > All devices. Then go to Bulk action you can activate eSIMs on up to 100 selected devices running Android 15 or later. Look at the below action.

Set Preview new device view to On, and then select a supported Android Enterprise device. At the top of the device overview pane, select Activate eSIM. Enter the carrier-provided activation code, and confirm the action.
