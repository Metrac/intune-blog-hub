Microsoft Intune MMA to Manage Multiple Work Accounts with Separate App Protection Policies

Saved for offline reading · Open original ↗

Key Takeaways

  • Microsoft Intune MMA to Manage Multiple Work Accounts with Separate App Protection Policies
  • MMA (Multiple Managed Accounts) lets users add and manage multiple MAM-enabled accounts in a single app.
  • Each account can have its own App Protection Policy, allowing admins to apply different security controls to different accounts.
  • MMA helps consultants, employees involved in mergers or acquisitions, and users working with accounts across multiple organisations.
  • One account can be MDM + MAM managed, while additional accounts can be MAM-only. Multiple MDM-managed accounts aren’t supported.
  • MMA works only with apps that support multiple identities. For example, Power Apps is currently out of scope. The feature is also rolling out gradually, so it may not yet be available in every tenant.

Multiple Managed Accounts (MMA) is useful for people who need to use more than one work account in the same app. An IT support engineer can use multiple company accounts in the same app to support different organisations. Each account can have separate app protection settings.

Table of Content

What is MMA?

MMA (Multiple Managed Accounts) is a feature in Microsoft Intune MAM that allows users to add and use multiple managed work accounts in the same supported app.

What Does MMA Mean for Intune Administrators?

MMA (Multiple Managed Accounts) allows users to add and use multiple managed work accounts in the same supported app. For example, a user working with two companies can use both company accounts in Outlook.

Can MMA Be Used with Every App?

No. MMA works only with apps that have been integrated to support multiple managed identities. Admins should check the supported apps and required versions before troubleshooting.

Are Intune-wrapped Apps Supported?

No. MMA currently supports apps integrated with the Intune SDK. Intune-wrapped apps are not supported.

Can Users Add Multiple Work Accounts to Any App?

No. Multiple managed accounts can be added only in MMA-enabled apps. Apps without MMA support may allow only one managed account.

Can the MMA Account be Different from the MDM Enrollment Account?

Yes. On an MDM-enrolled device, an MMA-supported app can allow a managed account that is different from the account used for device enrollment.

Microsoft Intune MMA to Manage Multiple Work Accounts with Separate App Protection Policies

MMA is currently available on selected Microsoft apps and platforms that support multiple identities. Users need to have a supported app version to use this feature. Microsoft plans to extend MMA support to additional apps and platforms in the future.
