Microsoft Intune Remote Help Client Upgrade with Enterprise App Catalog Apps

Key Takeaways

  • A new update view helps identify Enterprise App Catalog apps with newer versions.
  • Administrators can compare the provisioned version with the latest available version.
  • Administrators can quickly compare the currently installed version with the latest version available in the catalog.
  • Administrators can replace the existing app with the latest version through the update experience.

In this post we are discussing Microsoft Intune Remote Help Client Upgrade with Enterprise App Catalog Apps. Microsoft recently introduced an easier way to manage updates for applications available through the Enterprise App Catalog in Intune. The new experience helps administrators identify applications that have newer versions available and start the update process directly from the Intune admin center. With this update, administrators can view the current version of an application with the latest version available in the Enterprise App Catalog.

Microsoft Intune Remote Help Client Upgrade with Enterprise App Catalog Apps

Instead of manually setting up the updated application, Intune uses the application details available from the Enterprise App Catalog to simplify the process. Administrators can then review the updated application, configure the required assignments, and deploy it to the appropriate users or devices.

What’s New

Microsoft Intune now makes it easier to find Enterprise App Catalog apps that have a newer version available. Administrators can see the current version and the latest available version in one place. Admins can select the Update option to start the update process and use the latest version to replace the existing app. This helps simplify app updates and reduces the manual work involved in managing different application versions.

How to Update Enterprise App Catalog Apps using Intune

Sign in to the Microsoft Intune admin center and navigate to Apps > All Apps. The All Apps page provides a central view of the applications available in your Intune environment and allows you to manage applications across different platforms.

From All Apps, you can search for and select the application you want to manage. For this configuration, we are working with the Remote Help application available through the Enterprise App Catalog. This view helps you identify Enterprise App Catalog applications for which a newer version is available. You can search for Remote Help and review the version information displayed for the application. Here you can see the Latest available version shows the newer version available through the catalog.

After confirming that an update is available, select Remote Help to open its application details and continue with the update process. On the Remote Help application page, select Update to open the application update experience. Intune provides the latest application information from the Enterprise App Catalog and displays the Update application section, where you can review the available update before proceeding.

  • Under Supersede this app with the latest version, select Supersede app.
  • Intune creates a new application using the latest available package and establishes a relationship with the existing application.
