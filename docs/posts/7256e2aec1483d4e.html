Microsoft Entra Security Defaults Adds Individual Controls for MFA and Authentication Protection

Key Takeaways

  • Microsoft Entra Security Defaults Adds Individual Controls for MFA
  • Administrators can manage four security rules separately.
  • The update helps administrators manage security protections without disabling the entire Security Defaults configuration.
  • The new experience is currently in private preview for selected Microsoft Entra ID Free tenants.

In this post, we are discussing the Microsoft is introducing a new experience for Security Defaults in Microsoft Entra ID. This update allows administrators to manage individual security protections instead of enabling or disabling all protections together. Security Defaults help organizations protect user accounts from identity-related attacks, such as password spray attacks, phishing, and attempts to use stolen credentials. These settings provide basic security protection, especially for organizations using the free version of Microsoft Entra ID.

Microsoft Entra Security Defaults Adds Individual Controls for MFA and Authentication Protection

In this new Experience, Microsoft is introducing four individually configurable security rules. Administrators can manage each rule separately while keeping the other security protections enabled. This provides more flexibility when managing security settings in Microsoft Entra ID. Also, this change provides more flexibility in managing security protections while helping organizations protect user accounts from identity-based attacks.

What’s New in Microsoft Entra Security Defaults

Microsoft is introducing four individually configurable security rules in Microsoft Entra ID Security Defaults. These rules cover requiring multifactor authentication (MFA) for administrators, requiring MFA for all users, blocking legacy authentication, and blocking device code flow. Previously, administrators had to manage Security Defaults as a single setting. With this update, they can manage each security rule separately without affecting the other rules.

Note: The updated experience is currently in private preview for selected Microsoft Entra ID Free tenants. Eligible tenants will receive an invitation to participate.

Existing Security Defaults Configuration in Microsoft Entra ID

Administrators can access Security Defaults in the Microsoft Entra admin center by navigating to Entra ID > Overview > Properties. The Security Defaults section displays the current configuration and allows administrators to review whether the setting is enabled or disabled. Administrators to review whether the setting is enabled or disabled. As shown in the screenshot, administrators can select the available option to manage Security Defaults. This is the existing configuration, where security protections are managed together rather than individually.

Managing Security Defaults When Conditional Access Policies are Enabled

When an organization is already using Conditional Access policies, Microsoft Entra ID displays a message explaining that Security Defaults cannot be enabled in the current configuration. Administrators can use Conditional Access to configure custom policies that provide the same security protections as Security Defaults. This helps organizations manage their security requirements through Conditional Access instead of enabling both configurations together.
