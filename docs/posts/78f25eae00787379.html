Use web-based device enrollment for BYOD enrollment on iOS/iPadOS

Saved for offline reading · Open original ↗

By: Rishita Sarin - Product Manager 2 | Microsoft Intune

Web-based device enrollment is the recommended enrollment method for bring-your-own-device (BYOD) scenarios on personal iOS/iPadOS devices in Microsoft Intune. It provides a faster, more user-friendly enrollment experience while giving organizations the device management capabilities needed to protect work data without affecting a user’s personal data or apps.

In early 2027, we’re improving the web-based device enrollment user experience to make the flow more intuitive and easier to follow. Users can start enrollment from Microsoft Teams or Microsoft Outlook and complete the required enrollment and registration steps within the app context and with only one authentication prompt.

This update is part of our continued investment in web-based device enrollment and JIT registration for iOS/iPadOS. It also supports the transition toward web-based device enrollment becoming the default enrollment method for iOS/iPadOS in 2027 (refer to the Message center MC1476216 for details).

For personal iPhone and iPad devices (also known as bring-your-own device (BYOD)), organizations need an enrollment method that balances user privacy, data protection, and ease of use. Web-based device enrollment is designed for that BYOD model. Like app-based device enrollment with Company Portal, it supports a limited but appropriate set of management settings and actions for personal devices. This helps organizations protect work data while keeping personal data and apps separate.

Web-based device enrollment improves the user experience by letting users complete enrollment in Microsoft Teams or Microsoft Outlook instead of requiring Company Portal as the starting point. Web-based device enrollment is based on JIT registration allowing Intune to use Microsoft Authenticator and the Microsoft Entra ID SSO extension for device registration and single sign-on, which reduces user sign in during enrollment to one prompt.

The result is a BYOD enrollment path that is easier to explain, easier for users to follow, and better aligned with how users naturally begin work on a personal device.

The updated experience makes the enrollment path clearer from start to finish. Users are guided through the steps required to enroll the device, install the management profile, complete registration, and return to the work app they were trying to access.

The updated flow also improves transitions and handoffs between the browser, device Settings, Microsoft Authenticator, and supported work or school apps.

 

  • A faster, more guided BYOD enrollment experience for personal iOS/iPadOS devices.
  • Enrollment that starts from a supported work or school app, such as Microsoft Teams or Microsoft Outlook, or from an enrollment URL in Safari.
  • No requirement for Company Portal to be the starting point for enrollment.
  • JIT registration with Microsoft Authenticator and the Microsoft Entra ID SSO extension to reduce repeated sign-ins.
  • Management controls that help protect work data without affecting personal data or apps.
  • A clearer user path through Safari, device Settings, Authenticator, and back to work access.

JIT registration enables Microsoft Entra registration during enrollment without requiring Company Portal as the starting point for registration. JIT compliance remediation can then help users understand compliance status and required actions in the app they are already using.

This builds on the JIT registration and compliance remediation experience described in Use JIT registration and JIT compliance remediation for all your iOS/iPadOS enrollments.

If your organization still uses Company Portal as the starting point for BYOD enrollment on iOS/iPadOS, we recommend evaluating web-based device enrollment. Web-based device enrollment is the direction for iOS/iPadOS BYOD enrollment in Intune and will become the default enrollment method when admins create new iOS/iPadOS enrollment profiles or don’t have an enrollment profile configured expected in early 2027. Please note, there’s no impact on existing enrollment profiles.

To get ready, we recommend that organizations:

  • Set up web-based device enrollment for personal iOS/iPadOS devices.
  • Deploy Microsoft Authenticator as a required app for users enrolling iOS/iPadOS devices.
  • Configure or update the Microsoft Entra ID SSO extension policy for JIT registration.
  • Configure Conditional Access policies consistently for the most optimal enrollment experience with sign-in prompts

Additionally, it’s important to note that Company Portal is not being deprecated for iOS/iPadOS. Company Portal continues to support experiences beyond enrollment. However, Company Portal is not required as the starting point for web-based device enrollment. If your organization uses Company Portal after enrollment, you can continue to deploy it as a required or available app.
