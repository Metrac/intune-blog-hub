Microsoft Entra Identity Verification Integration with Conditional Access

Saved for offline reading · Open original ↗

Key Takeaways

  • Microsoft Entra Identity Verification Integration with Conditional Access
  • Conditional Access: Integrates Identity Verification into CA policies.
  • Verify identity before accessing sensitive sites.
  • Unmanaged Devices: Trigger verification for unmanaged device access.
  • Risk-Based Security: Require verification when user risk increases.
  • Stronger Protection: Make access decisions based on context and risk.

Microsoft Entra Identity Verification is being integrated with Conditional Access to strengthen access security. Organisations can require identity verification before users access sensitive SharePoint sites or resources from unmanaged devices. It also enables additional verification when user risk increases, helping organisations make smarter access decisions based on user context and risk.

Microsoft Entra Identity Verification Integration with Conditional Access

Microsoft Entra Identity Verification helps administrators manage and monitor users’ identity verification details. Admins can check verification status, review verification history, and track identity verification events. With Identity Verification coming to Conditional Access, organisations can add an extra verification step before users access sensitive resources. This helps improve access security and supports better identity protection.

Require identity verification

Users must present a valid Verified ID and complete a Face Check to confirm their identity before accessing the protected resources. This adds an extra layer of security and helps ensure that only verified users can gain access.
