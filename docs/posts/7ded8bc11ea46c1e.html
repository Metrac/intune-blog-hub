New Entra Device Access Profile in MS Global Secure Access Enables Private Connectivity Before Windows Sign-In

Saved for offline reading · Open original ↗

Key Takeaways

  • New Entra Device Access Profile in MS Global Secure Access
  • Enables private access to selected destinations before users sign in to Windows.
  • Supports first-time sign-in and authentication with credentials that are not cached on the device.
  • Enables password change and reset workflows that require connectivity to a domain controller.
  • Provides connectivity to domain controllers during sign-in for authentication, NTP time synchronisation, and Group Policy processing.
  • Allows Windows devices to contact on-premises management services such as SCCM and WSUS during startup.

Microsoft Global Secure Access (GSA) introduces Device Access, enabling private access connectivity to selected destinations before users sign in to Windows. This lets users sign in with credentials not cached on the device, including first-time sign-ins and after password changes or resets.
