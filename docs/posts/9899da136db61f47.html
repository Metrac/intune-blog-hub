What’s New in Intune

Microsoft has introduced Mobile Application Management (MAM) support for the Windows App. This capability provides additional protection for corporate data accessed through the Windows App when users connect to Windows 365 Cloud PCs. MAM support is particularly useful for organizations that allow employees to use personal or unmanaged Windows devices. Instead of relying only on device management, organizations can extend application-level protection to corporate data accessed through the Windows App. This helps organizations support flexible working environments while improving the protection of business information.

The new Windows 365 admin assistant in Microsoft Intune will help IT administrators investigate connectivity issues, identify possible causes, and get troubleshooting recommendations. Microsoft is also improving Cloud PC monitoring and reporting to make management easier.

  • Along with these improvements Microsoft is introducing new security and flexibility features across Windows 365.
  • These include MAM support for Windows App to protect corporate data on managed and unmanaged devices, improvements to Windows 365 Reserve and Flex, and a new in-session connection experience in Windows App.

Automate Business Tasks with Windows 365 for Agents

Windows 365 for Agents lets AI agents use a secure Cloud PC to work across business applications just like a user. As shown in the image, the agent accesses Excel, enters information into SAP, and completes a purchase request automatically. This helps organizations automate tasks across applications, including legacy systems that don’t have APIs, while maintaining enterprise security and governance

Intelligence Built into Cloud PC

Microsoft is introducing the Windows 365 Admin Assistant in the Microsoft Intune admin center to help IT administrators manage and troubleshoot Cloud PCs more easily. Currently available in Public Preview, the assistant can investigate Cloud PC connectivity problems based on the issues reported by administrators. It analyzes available diagnostic signals, identifies possible root causes, and recommends actions to resolve connection issues.

In the below screenshot, the administrator asks why a user’s Cloud PCs are experiencing connection failures, and the assistant investigates the issue and identifies DNS lookup failures followed by connection timeouts as the cause. IT administrators can use the assistant to investigate Cloud PC connectivity problems, identify possible root causes, and receive recommended troubleshooting actions.

  • The monitoring experience also provides connection health, user and device details, and configuration information in a centralized view.
