Microsoft Intune Ends Support for CNAME Auto-Discovery in Windows MDM-Only Enrollment

Saved for offline reading · Open original ↗

Key Takeaways

  • Microsoft Intune will end support for CNAME auto-discovery in Windows MDM-only enrollment starting January 15, 2027, or soon after.
  • The change affects organizations that rely on the EnterpriseEnrollment DNS CNAME record to discover the enrollment service.
  • Users may need to manually enter the Microsoft enrollment server URL during enrollment.
  • Windows MDM-only enrollment will continue to be supported, but CNAME-based auto-discovery will no longer be available.

In this post, we are discussing Microsoft Intune Ends Support for CNAME Auto-Discovery in Windows MDM-Only Enrollment. Microsoft recently announced that Microsoft Intune will end support for DNS CNAME-based auto-discovery in Windows MDM-only enrollment scenarios starting January 15, 2027, or soon after. This change affects organizations that use DNS CNAME records to automatically discover the Microsoft enrollment service during Windows device enrollment.

Microsoft Intune Ends Support for CNAME Auto-Discovery in Windows MDM-Only Enrollment

Currently, organizations can configure an Enterprise Enrollment DNS CNAME record to help Windows devices automatically locate the Microsoft enrollment service. This allows users to begin the enrollment process without manually entering the enrollment server URL. This change does not affect existing enrolled devices or Windows MDM-only enrollment itself. Organizations using Microsoft Entra join, Microsoft Entra hybrid join, and other enrollment methods that do not depend on CNAME discovery are also unaffected. Administrators should review their enrollment configurations and update their documentation before the change takes effect.

What Is Changing in Windows MDM-Only Enrollment?

Microsoft Intune allows administrators to check their DNS CNAME records using the CNAME Validation option. This helps confirm that the records are configured correctly for Windows MDM-only enrollment. To access this option, go to Microsoft Intune admin center > Devices > Enrollment > Windows > CNAME Validation. Starting January 15, 2027, or soon after, Intune will stop supporting CNAME-based auto-discovery for Windows MDM-only enrollment. If the enrollment URL is not provided automatically, users will need to enter it manually.

How the User Experience will Change

Currently, Windows can automatically find the Microsoft enrollment service during Windows MDM-only enrollment by using a DNS CNAME record. After January 15, 2027, or soon after, this method will no longer be supported. If the enrollment server URL is not provided automatically, users will need to enter it manually to continue the enrollment process.
