Microsoft Intune New Device Management Page Replaces Old Interface by Default for All Administrators

Saved for offline reading · Open original ↗

Key Takeaways

  • New Device Page Becomes the Default
  • Old Device Page Removed
  • Existing Features Remain Available
  • Updated Admin Permissions Required
  • Review Permissions and Documentation

Starting with the Microsoft Intune September 2026 release, the new device management page will become the default experience for all administrators, replacing the old device management page. The new interface provides a consolidated view of device properties, activity, management tools, and reports. All existing device management features will remain available, with improved navigation and usability.

Microsoft Intune New Device Management Page Replaces Old Interface by Default for All Administrators

Administrators must have the Managed devices/Update permission along with the specific permission required to perform individual device actions. For example, changing or removing a device’s primary user requires both Managed devices/Update and Managed devices/Set primary user permissions. Organizations should review administrator permissions, update internal documentation, and familiarize their IT teams with the new interface to ensure smooth device management.

What’s Changing in the New Microsoft Intune Device Experience

Administrators who navigate to Devices > All devices and select a device will automatically see the new device management page. The old device page will no longer be available after the transition. This update improves navigation, usability, and access to device information without removing existing device management features.

  • New Default Interface: All administrators will use the new device management page by default.
  • Existing Features Retained: All current device management capabilities remain available.
  • Additional Permission Required: Administrators must have the Managed devices/Update permission along with the specific permission needed for each device action.
  • Primary User Management: Changing or removing a device’s primary user requires both Managed devices/Update and Managed devices/Set primary user permissions.
  • Device Renaming Restrictions: Administrators without Managed devices/Update may be unable to rename devices.
