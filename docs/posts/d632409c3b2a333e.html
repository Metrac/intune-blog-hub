Support tip: Restore the Managed Home Screen Exit PIN

Saved for offline reading · Open original ↗

We identified and resolved a recent issue (IT1450132) that could cause the configured Managed Home Screen exit PIN to be removed from some existing Android Enterprise when updating older device configuration policies.  While a fix has been deployed to address this, if a policy was already affected, you will need update the affected policy or policies and ensure the Exit Kiosk Mode PIN is set before saving.

On an affected device, selecting Exit kiosk can display a message that a PIN to exit kiosk mode has not been set by the IT administrator, even though the policy was previously configured with one. See an example screenshot below. Note that this screen will also show on devices where you’ve intentionally disabled the Exit kiosk feature.

Figure 1: Android device in kiosk mode displaying a message that no PIN has been configured to exit kiosk mode and advising the user to contact an administrator.
  1. In the Microsoft Intune admin center, open the device restrictions policy assigned to the affected Android Enterprise dedicated devices.
  2. Under Device experience, confirm that Leave kiosk mode is set to Enable.
  3. Enter a new 4-6 digit value for Leave kiosk mode code.
  4. Save the policy and allow it to deploy to the affected devices.
  5. Verify that the new PIN can be used to exit kiosk mode.

The previous PIN cannot be recovered after it has been removed, so a new PIN is required. For more information, see Android template device settings list to restrict features using Intune.

If you need temporary access before the updated policy reaches a device, use the Suspend Managed Home Screen device action, provided the documented prerequisites are met.

Figure 2: Microsoft Intune admin center showing Android Enterprise device restriction settings, with the “Leave kiosk mode” option enabled and a kiosk exit code configured.

The service-side issue has been resolved. Administrators with previously affected policies should configure and deploy a new Managed Home Screen exit PIN, then verify the behavior on their devices.
