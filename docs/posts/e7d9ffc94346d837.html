Windows 11 23H2 Enterprise and Education | End of Security Updates and Upgrade Recommendations

Saved for offline reading · Open original ↗

Key Takeaways

  • Windows 11 23H2 Enterprise and Education editions will reach the end of updates.
  • The November 2026 Windows security update will be the last update for these editions.
  • After the end-of-updates date, these devices will no longer receive monthly security updates to protect against the latest threats.
  • Microsoft recommends upgrading eligible devices to a supported version of Windows 11.
  • Go to Settings > Windows Update > Check for updates. If an upgrade is available, select Download and install.

Windows 11, version 23H2 Enterprise and Education editions will reach end of updates on November 10, 2026. The November 2026 security update will be the final monthly security update available for these editions. After this date, devices running Windows 11 23H2 will no longer receive monthly security updates to protect against the latest security threats.

Recommended Upgrade Path for Windows 11 23H2

Microsoft recommends upgrading eligible Windows 11 23H2 Enterprise and Education devices to Windows 11 version 25H2 before support ends. Windows 11 25H2 Enterprise and Education editions are scheduled to receive updates until October 11, 2028. Although newer versions are available, administrators should follow Microsoft’s specific upgrade guidance and check device compatibility before planning the rollout.
