Security Copilot Included in Microsoft 365 E5 and E7 with Integrated Security Agents

Saved for offline reading · Open original ↗

Key Takeaways

  • Security Copilot is now included with Microsoft 365 E5 and E7 plans
  • AI agents are integrated across Microsoft Defender, Entra, Intune, Purview, and the Security Copilot portal.
  • Organizations receive 400 Security Compute Units (SCUs) per month per 1,000 licensed users, up to 10,000 SCUs per month.
  • Developer tools and APIs are included, allowing organizations to build custom security agents and integrations.
  • No admin action is required.

Security Copilot is now included with Microsoft 365 E5 and E7 plans, with integrated AI agents across Microsoft Defender, Microsoft Entra, Microsoft Intune, and Microsoft Purview. Organizations can access these Security Copilot capabilities without purchasing a separate license.

Security Copilot Included in Microsoft 365 E5 and E7 with Integrated Security Agents

Eligible organisations will also receive monthly Security Compute Units (SCUs) along with developer tools and APIs for creating custom security agents and integrations. No action is required to enable the entitlement, while some additional capabilities may incur separate charges.

Security Copilot Agents Across Microsoft Security

Microsoft Security Copilot agents are now available across Defender, Entra, Intune, and Purview. They help security teams work faster by using AI to handle security tasks and provide proactive support.

Starting September 24, 2026, organizations with Microsoft 365 E5 or E7 can use Security Copilot features and agents as part of their existing plan. No separate purchase or action is required.

Impact of Security Copilot on Your Organization

Organizations with Microsoft 365 E5 or E7 can access Security Copilot across key Microsoft security services. This includes Defender, Entra, Intune, Purview, and the Security Copilot portal, helping security teams use AI-powered capabilities across their existing security workflows.

Security Copilot

Security Copilot will be automatically included for Microsoft 365 E5/E7 organizations, with no separate purchase required. Organizations will receive monthly Security Compute Units and access to core AI-powered security experiences across Microsoft security services.

  • Security Copilot is included with Microsoft 365 E5/E7.
  • 400 Security Compute Units per month for every 1,000 licensed users, up to 10,000 SCUs per month.
  • Available across Defender, Entra, Intune, Purview, and Security Copilot portal.
  • APIs and tools are available to create custom agents and integrations.
  • Current security, compliance, and access policies will continue to apply.
