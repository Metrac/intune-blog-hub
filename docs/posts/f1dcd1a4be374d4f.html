Force Foreground Priority for All Tabs in Google Chrome using Intune Policy

Saved for offline reading · Open original ↗

Key Takeaways:

  • Google Chrome Foreground Priority for All Tabs
  • Helps to stop background tools from freezing
  • Saves battery and computer speed
  • Keeps your main tab fast

Let’s discuss about Force Foreground Priority for All Tabs in Google Chrome using Intune Policy. This policy controls whether background web content is forced to run at
foreground priority. Foreground Priority for All Tabs policy tells Google Chrome how to allocate your computer’s CPU power and memory to web pages running in the background.

Table of Contents

Force Foreground Priority for All Tabs in Google Chrome using Intune Policy

By default, modern web browsers intentionally slow down or “freeze” background tabs to lower CPU usage, keep your laptop quiet, and save battery life. This policy allows IT administrators to turn off that automatic slowdown. When enabled, the browser gives every single tab active or background the exact same highest priority.

Configure Chrome Foreground Priority for All Tabs Policy

Using Microsoft Intune you can quickly configure Chrome Foreground Priority for All Tabs. Sign in Intune Admin Center portal. Go to Devices >  Windows > Configuration > Create > New Policy.

Choosing Profile and Platform

After that, you can Create a Profile for the policy which you want to configure. To create a profile you have to select platform and profile type. Here I selected Windows 10 and later as the Platform and Settings catalog as the profile type. Then click on the Create button.

Basic Tab for Naming Policy

Basic Tab is used to give an identity for the policy by adding name and description. Here Name is Mandatory and Description is optional. After adding these details click on the Next button.

Configure Foreground Priority for All Tabs

The Configuration settings page is helps to select specific settings to create the policy. The Settings Catalog provides a huge number of settings. To select a settings click on the +Add settings hyperlink. Then you will get Settings Picker.  Choose Google Chrome > Force Foreground Priority for All Tabs. Then I close the Settings Picker.

Disable Foreground Priority for All Tabs

If this policy is set to Disabled or not set, the browser determines priority based on standard heuristics (e.g., deprioritizing content that is not visible, not playing audio, not participating in video calls...). Disable is the default value of this policy. If you like to go with this value, click on the Next button.

Enable Foreground Priority for All Tabs

If this policy is set to Enabled, all web content runs at foreground priority regardless of its visibility state. By enabling Eliminates timeouts in background web tools and data feeds. May slightly reduce battery life and active tab fluidity. Here I would like to enable this policy.

Scope Tags

By using scope tags you can restrict the visiblity of Foreground Priority for All Tabs Settings. It is helps to organize resources as well. Here I would like to skip this section, because it is not mandatory. Click on the Next button

Assign this Policy to Specific Groups

To assign the policy to specific groups you can use Assignment Tab. Here I click, +Add groups option under Included groups. I choose a group from the list of group and Click on the Select button. Again I click on the Select button to continue.

Final Step of Policy Creation

To complete the policy creation you can review all the policy details on the Review + create tab. It helps to avoid mistakes and successfully configure the policy. After varifying all the details click on the Create Button. After creating the policy you will get success message.

Device Check-in Status

The Device Check-in Status page shows whether the policy has succeeded or not. To quickly configure the policy and take advantage of the policy sync, the device on the Company Portal, Open the Intune Portal. Go to Devices > Configuration > Search for the Policy. Here, the policy shows as successful.

Client Side Verification with Event Viewer

If you get success message, that doesn’t means you will get the policy advanatges. To varify the policy successfully configured to client device check the Event Viwer.

  • Open Event Viewer: Go to Start > Event Viewer.
  • Navigate to Logs: In the left pane, go to Application and Services Logs > Microsoft > Windows > DeviceManagement-Enterprise-Diagnostics-Provider > Admin.
  • Filter for Event ID 814: This will help you quickly find the relevant logs.

Removing the Assigned Group from this Policy

Removing policy is necessary for some situation. If you want to remove the Assigned group from the policy, it is possible from Intune Portal. To do this open the Policy on Intune Portal and Edit the Assignments tab and Remove the Policy

How to Chrome Foreground Priority for All Tabs

You can easily delete the Policy from Intune Portal. From the Configuration section you can delete the policy. It will completely remove from the client devices.
