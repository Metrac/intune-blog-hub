Key Takeaways

  • KB5124010 is an optional September 2026 preview update, allowing users to test new features before the October Patch Tuesday release.
  • It updates Windows 11 25H2 to Build 26200.9550 and 24H2 to Build 26100.9550.
  • File Explorer receives improvements, including better handling and previewing of files downloaded from the internet.
  • The update introduces significant Bluetooth enhancements and allows users to remap the Copilot key.
  • The update can be installed through Windows Update or the Microsoft Update Catalog.

Windows 11 KB5124010 is an optional September 2026 Preview Update that allows users to try new features and improvements before the next Patch Tuesday release. It brings enhancements to Bluetooth and File Explorer, along with the ability to remap the Copilot key. The update advances Windows 11 25H2 to Build 26200.9550 and Windows 11 24H2 to Build 26100.9550. Users can install it through Windows Update or download the offline .msu installer from the Microsoft Update Catalog.

If you turn on the “Get the latest updates as soon as they’re available” option in Windows Update, optional updates may download automatically in the background. This setting is useful if you want to receive new Windows 11 features early. However, you can also skip the optional update because the same changes will be included in the regular October 13 Patch Tuesday update.

KB5124010: Windows Update vs. Offline .MSU Installation

Windows 11 KB5124010 can be downloaded through the Microsoft Update Catalog as an offline .msu installer for 64-bit and ARM64 devices. Microsoft recommends using Windows Update for normal installations, while the Update Catalog can be useful when Windows Update encounters errors.
