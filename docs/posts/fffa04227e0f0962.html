Microsoft Entra ID Ends SMS First-Factor Sign-In for Workforce Tenants

Saved for offline reading · Open original ↗

Key Takeaways

  • Microsoft Entra ID Ends SMS First-Factor Sign-In for Workforce Tenants
  • Microsoft Entra ID will block phone number + SMS OTP as a primary sign-in method starting February 1, 2027.
  • Organisations should find users who rely only on SMS first-factor authentication and check whether they have another registered sign-in method.
  • Microsoft recommends alternatives such as Passkeys, Windows Hello for Business, and FIDO2 security keys.
  • Pay special attention to shared devices, users without corporate smartphones, and recovery processes that depend on phone numbers.
  • Update enrollment instructions, help-desk procedures, break-glass plans, and user communications, and use a staged migration before February 1, 2027.

Microsoft is introducing a security-focused change that will prevent employees from using a registered phone number and SMS one-time passcode (OTP) as their primary sign-in method. If organizations do not prepare in advance, this change could disrupt access to Microsoft 365 and other Microsoft Entra-protected services.

Microsoft Entra ID Ends SMS First-Factor Sign-In for Workforce Tenants

Microsoft Entra ID will stop allowing users to sign in with a phone number and SMS one-time passcode as their primary sign-in method starting February 1, 2027. Organizations need to prepare for this change to avoid sign-in disruptions.

Administrators should identify users who currently depend only on SMS first-factor authentication and check whether they have another registered authentication method. This will help organizations identify accounts that may be affected by the retirement.

  • SMS will no longer be supported as a primary sign-in method.
  • The change affects users relying on phone number + SMS OTP for first-factor authentication.
  • Microsoft refers to this authentication method internally as SignInNoPassword.
  • Organisations should identify affected users before the change takes effect.
  • Users should register an alternative authentication method to avoid sign-in disruptions.

Preparing for the End of SMS First-Factor Authentication

Organisations should begin preparing users for the transition away from SMS-based first-factor authentication. Moving users to modern authentication methods, planning for frontline and shared-device scenarios, and updating support and recovery processes can help reduce sign-in disruptions before February 1, 2027.
